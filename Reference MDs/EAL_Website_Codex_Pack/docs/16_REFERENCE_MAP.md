## Cross-reference rules

- Treat composition, spacing and hierarchy as authoritative inspiration.
- Treat visible text/data as placeholder unless also defined in structured product data.
- Do not create different design systems per page. All references must resolve into the shared tokens/components defined in this pack.
- Maintain vehicle identity across images: body proportions, lighting signatures, wheels and model-specific styling should not drift between routes.
