# Technology Media Manifest

Technology media must explain a topic rather than imply a capability beyond the approved model, trim, market, software-version, or legal scope.

Every illustration or visualization needs:

- descriptive alt text or decorative designation;
- localized caption when it carries technical meaning;
- model/market/availability metadata where relevant;
- an accessible text/data alternative for charging curves, sensor overlays, diagrams, and animated systems.

Use the individual topic manifests for required slots, including 800V architecture, battery and charging, intelligent driving, software and connectivity, energy ecosystem, and safety.
