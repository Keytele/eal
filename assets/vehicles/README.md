# Vehicle Media Manifest

Each model folder contains the slots for an exact vehicle identity. Whenever an image represents a trim/color/wheel/interior combination, register those attributes in the media catalog.

Required shared categories:

| Category | Purpose |
| --- | --- |
| hero | Model overview and shopping hero media |
| exterior | Front, side, rear, and design-detail images |
| interior | Cabin, seating, display, storage, and material images |
| gallery | Editorial gallery imagery |
| configurator | Exact configuration renders and optional 360 frames |

Illustrative lifestyle media must be labeled as illustrative if it cannot represent the selected configuration exactly.
