# Commerce Media Placeholder Manifest

This folder is intentionally limited to neutral supporting media. Exact vehicle renders belong in the corresponding model configurator folder.

| Slot | Suggested filename | Ratio | Use |
| --- | --- | --- | --- |
| Build-save support | commerce-save-build | 3:2 | Optional save/share explainer |
| Finance education | commerce-finance-education | 3:2 | Finance overview only |
| Trade-in education | commerce-trade-in-education | 3:2 | Trade-in lead flow only |
| Reservation confirmation | commerce-reservation-confirmation | 3:2 | Nonessential confirmation visual |
| Booking confirmation | commerce-booking-confirmation | 3:2 | Nonessential confirmation visual |

No visual may state a price, payment, availability, delivery date, approval outcome, or legal term.

The Phase 56 confirmation and education slots are optional; exact vehicle media remains in the model manifests. See [../phase-50-60-image-manifest.md](../phase-50-60-image-manifest.md).
