# Editorial Media Placeholder Manifest

Use this directory for design, sustainability, brand-story, news, ownership, and support imagery that does not belong to a model or technology folder.

| Slot group | Suggested filename prefix | Required metadata |
| --- | --- | --- |
| Design philosophy | editorial-design- | Topic, locale, focal point, rights |
| Sustainability | editorial-sustainability- | Claim approval/source and market scope |
| Brand story | editorial-about- | Author/source, rights, locale |
| News hero | news-[slug]-hero | Author, publication date, social crop, rights |
| News inline | news-[slug]-inline-[n] | Caption/alt text, rights |
| Ownership/support | ownership-[topic]- | Model/market applicability, rights |

Do not use images to make unsupported environmental, safety, or technical claims.

Phase 50 news requires a hero image, social crop, and optional inline images only for an approved article. The exact slot naming and evidence gate are listed in [../phase-50-60-image-manifest.md](../phase-50-60-image-manifest.md).
