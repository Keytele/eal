# Global Media Manifest

Add reusable media only when it is not tied to a specific model/trim claim.

| Slot | Suggested filename | Intended use | Minimum delivery |
| --- | --- | --- | --- |
| Site texture/background | global-architectural-background | Subtle dark architectural background | 16:9 desktop and mobile-safe crop |
| Search fallback | search-empty-state | Nonessential empty-state illustration | 1:1 or transparent SVG/PNG, decorative by default |
| Maintenance fallback | maintenance-hero | Planned maintenance/unavailable page | 16:9 desktop and 4:5 mobile |
| Generic charging scene | global-charging-editorial | Editorial only, not model-specific proof | 16:9 desktop and 4:5 mobile |
| Generic accessibility/support art | support-editorial | Support/ownership noncritical visual | 3:2 desktop and 4:5 mobile |

Avoid stock imagery that conflicts with EAL's dusk architectural visual language.

Phase 50–60 also references `search-empty-state` and `maintenance-hero`; both are optional and must never be needed to understand a no-result, outage, or rollback state.
