# Contributing to EAL

All implementation work must follow the task and continuity conventions in `tasks.md` and `CONTINUITY.md`.

Before opening a pull request, complete the repository checks:

```sh
pnpm check
pnpm build
```

Use the pull-request checklist for public strings, accessibility, analytics, legal/data sourcing, and validation evidence. Provider secrets, unapproved production copy, prices, availability, technical claims, and customer data must never be committed.
